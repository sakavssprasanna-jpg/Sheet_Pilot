🚀 Excited to announce the launch of **SheetPilot AI** v1.0.0, a secure, voice-enabled spreadsheet copilot built for modern data workflows!

SheetPilot AI allows users to query, transform, and analyze spreadsheets (CSV/Excel) using natural voice and text commands. 

Key Features:
- **🎙️ Multilingual Speech Processing**: Speak naturally in English, Telugu, Hindi, and other languages; Gemini automatically transcribes and interprets user intent.
- **🛡️ Secure Execution Boundary**: Unlike traditional assistants that execute risky, LLM-generated Python code, SheetPilot compiles intents into a structured JSON schema, validating it against strict whitelists before executing operations using deterministic Pandas methods.
- **📊 Interactive Visualizations**: Automatically recommends and renders dark-themed Plotly Express charts.
- **🗂️ In-Memory Data Editing**: Edit values inline with an undo/redo state buffer.
- **📥 Styled Spreadsheet Export**: Automatically adjusts column widths and headers for clean Excel exports.
